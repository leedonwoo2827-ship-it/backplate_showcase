# 개발자 프레젠트 지원 에이전트

레포 폴더 + 화면 녹화 + 라이브 URL 을 넣으면 **20~40장짜리 발표 덱**이 나옵니다.
장마다 내레이션 음성이 붙고, 몇 장에는 영상이 임베드됩니다.

이 툴이 파는 것은 콘텐츠가 아니라 **기획**입니다. 개발자는 재료를 이미 갖고 있고,
없는 것은 그걸 발표물로 구성할 시간입니다.

```
setup.bat        (mac: ./setup.sh)     처음 한 번
run.bat          (mac: ./run.sh)       → http://localhost:5178
```

**API 키가 필요 없습니다.** Claude Code 구독 로그인을 그대로 씁니다.
터미널에서 `claude` 를 한 번 실행해 로그인해 두면 됩니다.

## 무엇을 어떤 차례로

**괄호 안은 앱이 하는 일**입니다. 괄호 밖이 사람이 보고 정하는 자리입니다.

```
1  원고 HTML 넣기            → (구조 읽기)  ★ 길이를 여기서 확인한다
2  목차 — 순서·제목 확정                    표지·마무리는 「+썸네일」로
3  (그림 지시문)                          → 09_이미지 에 JSON 두 개
4  (이미지·썸네일 JSON) → 다른 앱에서 그림 받기
5  (덱 전체 · 발음 대본 굽기)
6  (덱 전체 · 음성/자막 굽기)
7  (영상 렌더링) → 장별로 듣기 · 마스킹 → (다시 렌더링)
8  (모션 전체 굽기)                        유튜브 글 올리고 최종 청취
```

걸음마다 어디를 누르는지는 **[docs/01-매뉴얼.md](docs/01-매뉴얼.md)** 에 있습니다.

## 필요한 것

| | 없으면 |
|---|---|
| Python 3.10+ | 안 돕니다 |
| Claude Code 로그인 | Claude 단계가 안 돕니다 |
| ffmpeg | 프레임 추출·영상 변환이 안 됩니다 |
| `gh` CLI | 레포 수집이 안 됩니다 (영상만으로도 덱은 나옵니다) |
| voicewright + Supertonic-3 | 음성이 안 나옵니다. 덱·자막·큐시트는 전부 나옵니다 |

TTS 는 `showcase.config.json` 의 `tts` 에 경로를 적어야 돕니다:

```json
"tts": {
  "engine": "voicewright",
  "python": "…/.venv/Scripts/python.exe",
  "voicewright_dir": "…",
  "assets_dir": "…/assets"
}
```

성우 파일을 `07_음성/005.wav` 처럼 번호로 넣어 두면 **그 장은 합성하지 않습니다.**

## 하지 않는 것

- **다른 앱과 프로세스를 잇지 않습니다.** 이미지는 별도 앱(ChatGPT OAuth)이 만들고,
  접점은 `09_이미지/` 폴더 하나입니다. 인증 주체가 다른 것을 코드로 이으면 사고가 납니다.
- **LAN 공유를 하지 않습니다.** 이 앱은 호스트의 Claude 구독으로 돕니다.
- **API 키를 쓰지 않습니다.** 환경변수의 `ANTHROPIC_API_KEY` 는 무력화합니다.
- **에이전트가 네트워크를 만지지 않습니다.** `Bash`/`Write`/`WebFetch`/`WebSearch` 차단,
  레포는 호스트가 clone 하고 Claude 는 `Read`/`Grep`/`Glob` 만 씁니다.
