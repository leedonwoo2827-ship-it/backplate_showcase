JSON 형식이 처음이라면

⬇ 샘플 파일 받기 (ch99_script.json) — 받아서 그대로 끌어놓으면 바로 동작합니다.

꼭 필요한 건 scenes[] 안의 scene(번호)과 narration_text(읽을 문장) 둘뿐입니다.

{
  "chapter": 99,
  "scenes": [
    {
      "scene": 1,
      "narration_text": "읽을 문장입니다.",
      "srt_text": "자막에 넣을 문장 (생략하면 위와 동일)",
      "voice_style": "calm_female",
      "narration_seconds": 3.0
    }
  ]
}

voice_style은 config/voice_map.yaml로 M1~F5에 매핑됩니다. 매핑에 없으면 기본 화자로 떨어지고 경고가 뜹니다. 자세한 설명은 docs/batch-json.md 참고.

📦 전체 zip (음성+자막) 📝 챕터 자막 (.srt)

    대본 .json을 올리면 scene 목록이 카드로 표시됩니다. 카드마다 발음 (TTS 입력)과 자막 (SRT 출력)이 분리돼 있어 각각 따로 편집할 수 있습니다.
    좌측 전체 일괄 생성은 카드의 현재 텍스트로 합성하고, 발음변환 후 일괄 생성은 모든 카드에 한국어 발음 전환을 먼저 적용한 뒤 합성합니다. 카드별 생성/재생성 후에는 SRT 전체 생성으로 챕터 자막을 다시 합칠 수 있습니다.
